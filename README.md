# SysPriv-Proj1

## Overview

Academic privacy engineering project implemented with Spring Boot. It explores how data can be transformed to reduce identifiability and how privacy techniques can be evaluated against linkage attempts.

**Technologies and concepts:** Java, Spring Boot, data de-identification, linkage attacks, k-anonymity, differential privacy.

**Project focus:** Comparing practical privacy-preserving mechanisms and their limitations in data-processing scenarios.
